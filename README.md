# 🧭 AgenteAchaPet — Frontend

## 🚀 Visão Geral

O **AgenteAchaPet**, por ora um protótipo funcional, visa se desdobrar em uma plataforma colaborativa e acolhedira para apoiar pessoas na busca de seus entes de afetividade [por enquanto cães]. A ideia central é incentivar que cada busca seja uma jornada coletiva, com base em apoio mútuo, solidariedade e esperança.

> "Porque cada busca é um *esperançar*, é uma jornada coletiva."

## ✨ Funcionalidades atuais

Á rigor, as funcionalidades vão girar em torno das necessidades da comunidade e do quanto ela está disposta a custear pelos serviços pagos.

✅  Cadastro de busca com cartaz digital e link de compartilhamento

✅  Lista pública de buscas ativas

✅  Simulação de backend com `localStorage`

✅  Navegação fluida e linguagem acolhedora

✅ [A API já está em construção](https://github.com/vctmor/agenteachapet-api)

## 🤝 Filosofia

O projeto é inspirado nas relações simbióticas que o correm [no líquen, bem como na relação do lobo-guará com a planta lobeira](https://agenteachapet.vercel.app/#sobre). Com isto, permeiam o projeto os conceitos de mutualismo e protocooperação. Uma espécie de base afetiva para incentivar o trânsito da situação de vítima', de 'desaparecimento', para uma posição mais ativa - agora é dali para frente:

> **Cada busca ativa represente o início de um novo processo: o caminho se faz caminhando**.

Além disso, a nossa proposta é empregar uma estética acolhedora, um visual suave. Por enquando, imprimimos esta estética tão somente na linguagem textual, no sentido de lembrar que não somos um amontoado de desaparecimentos mas sim diversas jornadas de busca, sopros de vida, de _'esperançar'_.
