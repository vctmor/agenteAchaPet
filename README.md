# 🧭 AgenteAchaPet — Frontend

## 🚀 Visão Geral

O **AgenteAchaPet** um sistema  que visa fomentar que pessoas criem um risoma de apoio mútuo na busca do seu ente de afetividade [por enquanto cães]. A proposta é que ao longo das versões o sistema vá se tornando um risoma comunitário [uma espécie de rede social].

> "Porque cada busca é uma jornada coletiva."

## 📌 O que é

Simulação de API: localStorage no navegador. Atualmente estanos na versão de [protótipo](https://github.com/vctmor/agenteAchaPet/tree/prototipo_navegador), mas  [a API já está em construção](https://github.com/vctmor/agenteachapet-api)

Na versão atual, o **AgenteAchaPet** funciona como um mural virtual de cartazes de busca:

✅ Quem sentir pode cadastrar, dar início, a uma busca.

✅ O sistema gera um cartaz digital com as informações do bichinho e um link de compartilhamento.

✅ O cartaz é incluso na lista de buscas ativas, que é pública.

✅ Toda pessoa pode acessar essa lista, visualizar e compartilhar o link na internet para ampliar o alcance.

## 🤝 Filosofia

O projeto é inspirado nas relações simbióticas que o corrrem no líquen, bem como dentre o lobo-guará e a planta lobeira. Com isto, permeiam o projeto os conceitos de mutualismo e protocooperação. Uma espécie de base para inceitivar o trânsito da situação de vítima', de 'desaparecimento', para uma posição mais ativa - agora é dali para frente:

> **Cada busca ativa represente o início de um novo processo: o cocaminho se faz caminhando**.

A nosssa proposta é empregar uma estética acolhedora, um visual suave. Por enquando, imprimimos esta estética tão somente na linguagem textual, no sentido de lembrar que não somos um amontoado de desaparecimentos, mas sim diversas jornadas de busca, sopros de vida, de _'esperançar'_.
